# Acceso a Datos · DAM 26/27

Apuntes, ejercicios y prácticas de la asignatura **Acceso a Datos** de 2.º de Desarrollo de Aplicaciones Multiplataforma (DAM), curso 2026/2027.

## De qué trata la asignatura

Acceso a Datos enseña cómo una aplicación guarda, lee y gestiona información de forma persistente: desde trabajar directamente con ficheros hasta conectarse a bases de datos relacionales, objeto-relacionales y documentales, pasando por los ORM que traducen objetos del programa a tablas. El objetivo final es saber construir los componentes de una aplicación que se encargan de los datos.

## Qué hay en el repositorio

| Carpeta | Contenido |
|---|---|
| `Clases/001-Manejo de ficheros` | Lectura y escritura de ficheros de texto y binarios, y formatos de intercambio. |
| `Clases/002-Manejo de conectores` | Conexión de una aplicación con una base de datos relacional mediante conectores. |
| `Clases/003-Herramientas de mapeo objeto relacional (ORM)` | Cómo un ORM relaciona clases y objetos con tablas y registros. |
| `Clases/004-Bases de datos objeto relacionales y orientadas a objetos` | Modelos de datos que almacenan objetos directamente. |
| `Clases/005-Bases de datos documentales` | Bases de datos NoSQL basadas en documentos. |
| `Clases/006-Programación de componentes de acceso a datos` | Diseño de la capa de datos de una aplicación. |
| `Ejercicios/` | Ejercicios y prácticas de la asignatura. |
